# Deployment checklist (Streamlit Community Cloud)

1. Create a GitHub repository and upload the contents of this project folder (not the ZIP itself).
2. Confirm `app.py`, `reconciliation.py`, `requirements.txt`, `data/`, and `tests/` are at the repository root.
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. Choose **Create app**, select the repository, branch, and `app.py` as the main file.
5. Deploy. Wait for the build to finish, open the generated public app URL, and test the sample data and CSV download.
6. Put the real deployed URL in your submission. Do not submit a guessed or placeholder URL.

If the platform asks for a Python version, use Python 3.11 or 3.12 for a straightforward dependency setup.
